# ML & MLOps Learning Path

Practice folder for learning ML and MLOps alongside the InsureX Nexus AI project.
Follow the weeks in order. Each week has a starter notebook with tasks.

## Setup (do this once)

```bash
cd ml-learning
python -m venv .venv
source .venv/Scripts/activate   # Windows Git Bash; use .venv\Scripts\activate in PowerShell
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

Start Jupyter with `jupyter notebook` and open a week's notebook.
